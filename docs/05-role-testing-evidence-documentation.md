# Role 4: Testing, Evidence, and Documentation

## Purpose

Coordinate verification, submission evidence, detailed-design updates, reflection, and report assembly.

## Main responsibilities

- define the testing strategy
- coordinate unit and integration tests
- ensure each business area has successful and invalid cases
- collect build and execution evidence
- maintain the design change log
- coordinate the detailed class diagram
- document class, responsibility, collaborator, bootstrap, and scenario changes
- assemble screenshots or video evidence
- prepare the final report structure
- maintain the contribution and collaboration records

## Testing scope

### Unit tests

- entity invariants
- state transitions
- assignment validation
- payment validation
- exception resolution
- report period validation

### Integration tests

- API request to persistence flow
- successful and invalid requests
- object creation relationships
- retrieval after persistence
- cross-feature handoff

## Evidence required for each scenario

- empty or starting screen
- correct input
- incorrect input
- validation message
- edit, deletion, or change of mind
- successful completion
- sample output
- final persisted state

## Documentation responsibilities

The report must explain:

- class-level changes and non-changes
- responsibility and collaborator changes
- bootstrap changes
- sequence scenario changes
- strengths of Assignment 2
- missing or flawed parts of Assignment 2
- interpretation required during implementation
- lessons learnt
- architecture style
- build, deployment, and execution process

## Important limitation

This role coordinates evidence and documentation. It does not write every member's contribution for them. Each role must supply accurate technical notes and review the final wording.

## Definition of done

- tests run successfully
- build evidence is captured
- four scenarios are demonstrated
- all design changes are justified
- Assignment 2 is attached as required
- cover sheet and contribution document are complete
