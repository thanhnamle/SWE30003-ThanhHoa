# SmartFM Assignment 3 Work Plan

This folder contains the Assignment 3 implementation plan for SmartFM.

The documents divide the work by **role**, not by member name. The team can decide who takes each role based on skills, availability, and workload.

## Recommended roles

1. Domain and Application Logic
2. API, Persistence, and Integration
3. Frontend and User Experience
4. Testing, Evidence, and Documentation

The roles are not isolated. All four roles should review the final detailed design and the four implemented business areas.

## Minimum business coverage

The implementation should demonstrate at least four complete business areas:

- customer and order handling
- shipment and resource assignment
- invoice, simulated payment, and receipt
- tracking, exception handling, and operational reporting

The team should decide how these business areas are distributed across the roles.
